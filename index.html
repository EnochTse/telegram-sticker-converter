GIF / MP4 → Telegram Sticker

Converts in your browser — nothing is uploaded. Output meets Telegram's video sticker rules: WEBM · VP9 · no audio · ≤3 s · ≤30 fps · ≤256 KB.

1 · Source

Choose a file or drop it here GIF, MP4, WEBM, MOV — or a PNG/JPG/WEBP for a static sticker

2 · Settings

Video stickers are flattened onto this colour (browser VP9 encoders can't write an alpha channel).

3 · Result

    Then open @Stickers in Telegram: /newvideo for a video sticker pack, /newemojipack for emoji, /newpack for static stickers. A 100×100 video emoji also works as a pack icon.

    Needs a browser with WebCodecs VP9 encoding — current Chrome, Edge or Firefox on desktop or Android. GIF decoding uses the ImageDecoder API (Chrome, Edge, Firefox).
